# Another Percent Timer

Рабочий день на экране ретротелевизора, отдельная неоновая вывеска и лёгкий VHS-эффект. Нативные HTML/CSS/JS, Three.js 0.170.0 и локальные шрифты из Google Fonts. Все runtime-ресурсы лежат в репозитории; внешних запросов для работы приложения нет.

## Запуск

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Сборка и npm не нужны. Нужен HTTP-сервер для ES-модулей и текстуры.

## Как пользоваться

На первом входе форма начала и конца дня находится внутри кинескопа, а отдельная вывеска показывает **ANOTHER PERCENT TIMER**. После сохранения она меняется на **ДО КОНЦА ДНЯ ОСТАЛОСЬ**. Нажатие на цифры или `% / Ч:М` переключает проценты и оставшееся время. Расписание внизу экрана снова открывает форму.

Настройки хранятся в `localStorage` под ключом `after-work.schedule`. Используется местное время браузера. Поддерживаются ночные смены. Процент идёт от 99 до 1, после завершения — 0; время округляется вверх до минуты. Начало и конец не могут совпадать. После окончания ночной смены до следующего старта показывается ожидание следующей смены.

## Визуальная сцена

Телевизор — детализированный статичный рендер (`assets/retro-tv.png`), выведенный через Three.js. Интерактивный HTML-интерфейс совмещён с кинескопом. Фотографические материалы, отражения и округлая форма встроены в изображение; движущейся 3D-модели телевизора нет. Без WebGL тот же рендер выводится обычным изображением, а таймер продолжает работать.

Параллакс применяется только к отдалённому фону: максимум ±3 px по горизонтали и ±2 px по вертикали, с плавным переходом. Телевизор, экран, форма и вывеска неподвижны. На сенсорных экранах и при `prefers-reduced-motion` параллакс отключён.

VHS-слой включает строки развёртки, слабое зерно, расслоение цвета и медленную полосу трекинга. `prefers-reduced-motion` отключает анимацию и помехи.

## Проверки

```sh
node --test tests/timer.test.mjs
```

В браузере: заполнить форму, проверить смену вывески, переключить метрику, изменить расписание, перезагрузить страницу. При движении курсора границы телевизора и экрана должны оставаться неизменными. Проверить мобильный размер и режим без WebGL.
