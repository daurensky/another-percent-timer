# После работы

Неоновые 3D-песочные часы до конца рабочего дня. Нативные HTML/CSS/JS, Three.js 0.170.0 (локальная копия с MIT-лицензией), Google Fonts.

## Запуск

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Откройте сайт через HTTP. Сборка и npm не нужны. Время начала и конца хранится в `localStorage` под ключом `after-work.schedule`. Часовой пояс — локальный часовой пояс браузера. Поддерживаются ночные смены. Процент идёт от 99 до 1, после завершения — 0; оставшееся время округляется вверх до минуты. Равные начало и конец не допускаются.

Нажатие на цифры или кнопку переключает проценты и часы/минуты. В последние 10% смены заголовок начинает светиться разными цветами. `prefers-reduced-motion` отключает мерцание и переходы. При отсутствии WebGL таймер продолжает работать. Время после ночной смены и до следующего её начала отображается как ожидание следующей смены.

## GitHub Pages

Workflow `.github/workflows/pages.yml` публикует сайт при push в `main`. В Settings → Pages выберите Source: **GitHub Actions**, если автоматическое включение недоступно. Адрес: `https://daurensky.github.io/another-percent-timer/`.
