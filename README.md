# Another Percent Timer

Рабочий день на экране объёмного ретротелевизора. Нативные HTML/CSS/JS, Three.js 0.170.0, CSS3DRenderer и локальные шрифты из Google Fonts. Все runtime-зависимости лежат в `vendor/`; внешних запросов для работы приложения нет.

## Запуск

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Сборка и npm не нужны. Нужен HTTP-сервер: ES-модули и файл объёмного шрифта загружаются относительно страницы.

## Как пользоваться

На первом входе форма начала и конца дня появляется внутри кинескопа, вывеска показывает **ANOTHER PERCENT TIMER**. После сохранения вывеска меняется на **ДО КОНЦА ДНЯ ОСТАЛОСЬ**. Нажатие на цифры или `% / Ч:М` переключает проценты и оставшееся время. Нажатие на расписание внизу экрана снова открывает форму.

Расписание хранится в `localStorage` под ключом `after-work.schedule`. Используется местное время браузера. Поддерживаются ночные смены. Процент идёт от 99 до 1, после завершения — 0; время округляется вверх до минуты. Начало и конец не могут совпадать. После окончания ночной смены до следующего старта показывается ожидание следующей смены.

## 3D и эффекты

`television.js` создаёт корпус, скобу, ручки, подставку и вывеску с экструдированными буквами. HTML-интерфейс закреплён на экране через CSS3DRenderer и поворачивается синхронно с моделью. Курсор слегка меняет угол обзора; на сенсорном экране сцена остаётся неподвижной. VHS-слой включает scanlines, зерно, дрейф яркости, цветовое расслоение и полосу трекинга. `prefers-reduced-motion` отключает движение и помехи. При отсутствии WebGL включается плоский интерфейс с работающим таймером.

`vendor/sign-font.json` содержит нужные символы Unbounded; лицензия — `vendor/fonts/unbounded-LICENSE.txt`. Дополнения Three.js распространяются под той же MIT-лицензией, что и Three.js (`vendor/THREE-LICENSE.txt`).

## Проверки

```sh
node --test tests/timer.test.mjs
```

При проверке браузером: заполнить форму, проверить смену вывески, переключить метрику, изменить расписание и перезагрузить страницу. Проверить WebGL canvas, параллакс, мобильный размер и режим без WebGL.
